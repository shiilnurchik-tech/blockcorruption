# blockcorruption

Мод для Minecraft (Fabric, цель — 1.21.11): «блоковая коррупция» по мотивам
Animation vs. Minecraft Shorts Алана Беккера — чёрный глитч, который появляется
при перегрузке процессора/чанка или злоупотреблении командными блоками,
взрывается в небе, заражает блоки полностью чёрной текстурой, мельтешит
случайными блоками по кайме, накладывает камерный эффект и чёрный HUD рядом
с собой и открывает разломы в другие места мира.

Состав репозитория:

- `libs/immersive-portals/` — vendored исходник
  `eoNaho/ImmersivePortalsMod-fork` @ `port/26.1.2`
  (SHA `eae593cf`, Apache-2.0) для разломов-порталов, в процессе обратного
  порта на 1.21.11. См. `PORTING-1.21.11.md`.
- Код самого мода коррупции — следующий этап.

Сборка (на живой машине, JDK 21 + доступ к maven.fabricmc.net /
maven.minecraft.net / Modrinth):

```bash
cd libs/immersive-portals && ./gradlew build
```

В этой песочнице нет JDK и maven-доступа, поэтому состояние порта —
source-level; статус и план см. в `PORTING-1.21.11.md`.
